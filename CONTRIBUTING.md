# Contributing

Hissa qo'shganingiz uchun rahmat!

1. Repozitoriyni fork qiling va yangi branch oching (`git checkout -b fix/short-description`).
2. Tarjima matnlari uchun mavjud uslub va ohangga rioya qiling (rasmiy, `:attribute` kabi placeholder'larni saqlab qoling).
3. O'zgarishlaringizni tekshirish uchun testlarni ishga tushiring:

   ```bash
   composer install
   vendor/bin/phpunit
   ```

4. Pull request oching va nima o'zgarganini va nima uchun o'zgartirganingizni qisqacha yozing.

## Xatolik haqida xabar berish

Xato yoki noto'g'ri tarjimani topsangiz, [Issues](https://github.com/shoyim/laravel-uz-lang/issues) bo'limida yangi masala oching.
